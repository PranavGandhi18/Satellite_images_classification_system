Export & your own tools

CSV. Download every stored prediction as CSV (one row per tile, all 7 class probabilities, flags, and the latest review). The Filter tab's export button applies the current filters.

Read-only SQL. The results live in one SQLite file. Analysts can query it with any SQLite client, opened read-only so the service's writes are never blocked:

sqlite3 "file:/workspace/galaxi_button/data/tiles.db?mode=ro"

-- tiles (one row per image), predictions (append-only), reviews (append-only), models
-- views: current_predictions (latest per tile and model), current_reviews (latest per tile)
SELECT p.label, p.status, COUNT(*) FROM current_predictions p GROUP BY 1, 2 ORDER BY 1, 2;
SELECT t.source_name, p.label, p.confidence, r.label AS analyst
FROM current_predictions p JOIN tiles t USING (tile_id) LEFT JOIN current_reviews r USING (tile_id)
WHERE r.label IS NOT NULL AND r.label != p.label;          -- where analysts disagreed with the model
